# Green Technologies

Marketing site for Green Technologies — Website Development, Business Software, and Digital Marketing.

## Stack

- [Vite](https://vite.dev) + React 19 + TypeScript
- [Tailwind CSS v4](https://tailwindcss.com)
- [lucide-react](https://lucide.dev) icons

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
